# 🛠️ banditofsmoke: my workbench

I opened this account in 2024 to learn git. It was meant to be the throwaway one, and I never threw it away: it's where my products get built now, most of them in private repos.

If you're here to see what I've shipped, or to hire me, my main profile is **[@Sletch](https://github.com/Sletch)**.

## 🏗️ What gets built here

**🏢 [Sletcher Systems](https://www.sletchersystems.com)**<br>
My agency site, in English, Afrikaans, isiXhosa and isiZulu, with the enquiry form, the analytics and the admin dashboard behind it built by me. Private repo, live site.

**🧠 [UTTU](https://www.sletchersystems.com/uttu)**<br>
An AI assistant I'm building to run on your own computer instead of someone else's cloud. It talks with an AI model on the same computer and remembers what was said, and nothing it does happens until a rule allows it and a record of it is written down first. It is in build and private for now; every test it has run, and everything it does not do yet, is on its page.

**🧪 [Git From Zero](https://git-lesson.sletchersystems.com)** · [code](https://github.com/banditofsmoke/01-git-and-github)<br>
Takes someone who has never opened a terminal through to branches, pull requests and fixing a merge conflict, with a small git engine of my own in the sandbox.
